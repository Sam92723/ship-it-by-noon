# My app

**Domain:** hiking log for places in western washington

**User story:** As an avid hiker, I need to keep track of the hikes I have gone on, so that I know which hikes I went on, how many miles I have walked, and which ones I still have left to go.

**What the user types or picks:**
- Need to check off a hike when I get it done
- add certain hikes to my schedule
- want to add a photo of that hike 
- keeps track of the miles i walked and when
